💡 Price Wise - Feedback & Issue Tracker
ยินดีต้อนรับสู่พื้นที่สำหรับแจ้งปัญหาและเสนอแนะฟีเจอร์สำหรับแอปพลิเคชัน Price Wise (Smart Shopping) 🛒
แอปพลิเคชันนี้สร้างขึ้นเพื่อช่วยคำนวณและเปรียบเทียบความคุ้มค่าของราคาสินค้าในห้างสรรพสินค้าอย่างแม่นยำ หากคุณพบข้อผิดพลาด (Bug) หรือมีไอเดียฟีเจอร์ใหม่ๆ สามารถแจ้งพวกเราได้ผ่านทางนี้ครับ!

📌 วิธีการแจ้งปัญหาหรือเสนอแนะ (How to Report)
คุณสามารถแจ้งเรื่องได้ง่ายๆ ผ่านทาง GitHub Issues โดยทำตามขั้นตอนดังนี้:
คลิกที่ปุ่ม New Issue (กรุณาเปลี่ยน YOUR_USERNAME เป็นชื่อผู้ใช้ GitHub ของคุณ)
เลือกหมวดหมู่ที่ต้องการแจ้ง:
🐛 Report a Bug (แจ้งปัญหาการใช้งาน) - พบข้อผิดพลาด การคำนวณผิด หรือหน้าตาแอปแสดงผลเพี้ยน
💡 Feature Request (เสนอแนะฟีเจอร์ใหม่) - อยากให้เพิ่มฟุตเตอร์ หมวดสินค้าใหม่ หรือตัวแปลงหน่วยอื่นๆ
กรอกรายละเอียดตามแบบฟอร์มแล้วกด Submit new issue
📋 แบบฟอร์มการแจ้งเรื่อง (Templates)
